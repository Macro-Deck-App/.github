## Macro Deck

Turn a phone, tablet, or web browser into a control surface for your PC.

Macro Deck is the open-source macro pad for Windows, macOS and Linux. Build your setup from buttons, sliders, media controls and live widgets, and control apps, services and devices from one place.

**Macro Deck 3 is in beta.** Download it from [macro-deck.app](https://macro-deck.app).

### What you can do

- Arrange profiles, folders and widgets: action buttons, sliders, clocks, history graphs, weather and a music player
- Run actions on a short press, long press, double tap or event, and build flows with If / Else, Repeat and Wait
- Automate things without a button, for example on a schedule or when OBS starts streaming
- Give every button your own colors, icons, fonts, borders and states
- Connect OBS Studio, Home Assistant, Spotify, Twitch, Discord, Streamer.bot, Voicemeeter and more with built-in integrations
- Use any browser on your network as a deck, including browser-based game overlays

### Build a plugin

Plugins can add actions, events, variables and their own widget types. Start with the [plugin quickstart](https://docs.macro-deck.app/introduction/quickstart/) in the documentation.

### Macro Deck 2
