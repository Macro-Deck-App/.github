## Control and automate your setup with Macro Deck

Macro Deck is a free and open-source macro pad and automation tool for Windows.

Use your phone, tablet or browser as a customizable control surface for streaming, gaming, smart home control and everyday workflows.

### Features
- Fully customizable macro pads and profiles
- Actions for streaming, gaming and automation
- Extendable through community plugins
- Variables and dynamic button content
- Multiple profiles and unlimited folders
- Built-in plugin and icon pack manager
- Web client for additional devices
- Free and open source
